# Computer Network Project

This repository contains the core codebase for the Computer Network Project.

---

## How to Run

To install the required packages, run this command in the root directory:
```sh
python3 -m pip install -r requirements.txt
```

To run the chat application, run this command in the root directory:
```sh
python3 -m lanchat
```
