# Computer Network Project

This repository contains the core codebase and custom socket libraries (`TCP` / `UDP`) for the Computer Network Project.

---

## Project Structure

```text
├── configs/                # Configuration files (.toml) for client, server, logging, and UI
├── external_libs/          # Standalone files or source code of external dependencies
├── logs/                   # Runtime session log files generated by CNLogger
└── script/
    └── lib/
        └── v1/             # Core internal socket & utility library (v1)
            ├── client/     # ClientTCP and ClientUDP implementations
            ├── server/     # ServerTCP and ServerUDP implementations
            ├── UI.py       # Terminal colorized output formatter
            ├── cn_logging.py       # Instance-based file & console logger
            └── common_functions.py # Shared socket utilities (e.g., port finder)
```

---

## Frequently Asked Questions (FAQ)

#### Q: Where should I put external libraries?
**A:** Place all source codes or standalone files of external dependencies inside the designated directory:
`./external_libs/`

#### Q: What code should we commit?
**A:** For the time being, **focus completely on finishing and testing internal libraries**. Keeping them self-contained and modular now will ensure an easy assembly and integration phase later in the development cycle.
